# TERRIFIC ENGLISH CHANNEL app

Telegram Mini App канала TERRIFIC.ENG.CHANNEL: тест на уровень, рабочие тетради, курсы.

Открыть в Telegram: https://t.me/TerrificCommunityBot/terrific_channel

## community/ — приложение клуба TERRIFIC.COMMUNITY

Telegram Mini App платной группы: тест, новое за неделю, материалы с рабочими тетрадями, карточки, прогресс, разговорный клуб.
Адрес: https://terrificenglishenglish.github.io/terrific-channel-app/community/
Данные (материалы, карточки, ссылки на части тетрадей) подтягиваются из Google-таблицы — для новых недель код менять не нужно.
